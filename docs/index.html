Icons with a lacquer finish.

Original glossy 3D-style icons, lit from one light with a crisp edge, a window reflection and a little glow inside. Drawn as code, not traced from any emoji or icon set.

git clone https://github.com/JassiSingh08/gloss-icons

Apps: use the WebP

Pick the size that matches your largest display: 128 px covers about 42 pt on a 3x screen. A bitmap is far cheaper in a long list than drawing gradients and blurs live.

<Image source={require('./icons/heart.webp')}
       style={{ width: 40, height: 40 }} />

Web: SVG or WebP

Use the SVG where it should scale with the page, and the WebP in lists and grids.

<img src="dist/webp/128/heart.webp"
     width="64" height="64" alt="Heart">

Draw your own

Every icon is a small file that only describes shape and colour. Light, gloss, edge and shadow come from one shared engine, so new icons match automatically.

npm install
npm run build
