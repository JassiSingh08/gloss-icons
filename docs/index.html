Every emoji.
Lacquered.

Original glossy icons for every emoji, lit from one light with a crisp edge and a little colour glowing inside. Drawn as code, not traced. SVG and WebP, free for anything under MIT.

Use them anywhere.

Every icon ships as an optimised SVG and as WebP at 32, 64, 128 and 256 px. manifest.json lists each one with its emoji, group, tags and sizes, so an app can swap an emoji for its icon.

In apps, use the WebP that matches your largest size: 128 px covers about 42 pt on a 3x screen, and a bitmap is far cheaper in a long list than drawing gradients live.

Each icon is a short file that only describes shape and colour; light, gloss, edge and shadow come from one shared engine, so new ones match without trying.
